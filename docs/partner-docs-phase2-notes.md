# 파트너 문서 2단계 메모 (내부용)

## 카카오톡 링크 카드(오픈 그래프) 검토

- 지금 발송은 앱의 **공유 시트 / 링크 복사 / 이메일**이 중심입니다.
- 카카오톡에서 “카드”처럼 제목·미리보기 이미지가 보이게 하려면:
  1. **공개 HTTPS URL**에 문서 안내 페이지가 있어야 하고
  2. 그 HTML에 `og:title`, `og:description`, `og:image` 메타가 있어야 합니다.
- GitHub Pages(공개)에 정적 HTML을 두면 OG는 가능하지만, **내부 문서는 올리면 안 됩니다.**
- 카카오 개발자 콘솔의 링크 미리보기/스크랩 API는 별도 앱 키·도메인 등록이 필요합니다.
- **이번 단계 결론:** 연동은 보류. 공개 승인 문서용 랜딩 페이지를 나중에 만들 때 OG 메타를 넣는 쪽이 안전합니다.

## 내부 문서를 비공개로 두는 방법 (R2)

- 공개 GitHub + `docs_public/` + 웹 빌드 assets는 **주소를 아는 누구나** 받을 수 있습니다. 내부 파일은 넣지 마세요.
- 권장: **Cloudflare R2 비공개 버킷** + 관리자만 짧은 시간 유효한 **서명 URL**로 열람.
- 앱은 Firestore 메타(`audience: internal`, `url` 또는 object key)만 두고, 바이트는 R2에서만 가져옵니다.
- Firebase **Blaze**는 Cloud Functions로 서명 URL을 만들 때 필요할 수 있습니다.  
  대안: 이미 쓰는 **R2 + aws_signature_v4**(앱에 있음)로 관리자 기기에서만 서명 — 키를 클라에 두면 위험하므로 **서버/엣지 워커**가 더 안전합니다.
- Storage(Firebase)는 이 프로젝트 정책상 쓰지 않습니다.
