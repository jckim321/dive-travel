# 파트너 문서 4단계 메모

원래 계획의 1~3단계 다음에 이어서 한 작업입니다.

## 이번에 한 일

- **공개 랜딩 + OG:** `web/partner-docs/*.html` — 카카오·메신저 링크 미리보기용 (초안 표시 + noindex)
- **공유 링크:** 관리자 문서 발송 시 랜딩 URL 사용

## 나중 단계로 둔 것

- 파트너 「서류 제출 완료」 표시
- 기한 지난 리마인더 일괄 발송 큐

## 아직 서버 메일이 없는 이유

Cloud Functions + 메일 서비스(예: SendGrid)가 필요합니다. 지금은 `partner_email_outbox`에 쌓고, 관리자가 mailto로 보냅니다.
