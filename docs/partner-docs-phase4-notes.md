# 파트너 문서 4단계 메모

원래 계획의 1~3단계 다음에 이어서 한 작업입니다.

## 이번에 한 일

- **공개 랜딩 + OG:** `web/partner-docs/*.html` — 카카오·메신저 링크 미리보기용
- **공유 링크:** 관리자 문서 발송 시 랜딩 URL 사용
- **파트너 서류 제출:** 의향서 접수 후 「서류 제출 완료」로 진행 상태 변경
- **재안내:** 기한 지난 신청을 발송 큐에 일괄 넣기 (서버 메일 자동발송은 아직 없음)

## 아직 서버 메일이 없는 이유

Cloud Functions + 메일 서비스(예: SendGrid)가 필요합니다. 지금은 `partner_email_outbox`에 쌓고, 관리자가 mailto로 보냅니다.
